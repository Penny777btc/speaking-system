# 🗺️ B1 → C1 一年路线图

> 开始日期:____(填你的第一天) · 目标:12 个月后达到 C1
> **每季度末对项目说「月度模考」做一次测评,通过了才升级下一季度**(同时把 ChatGPT 项目指令里的「当前水平参数」调高一级)。

## 每日节奏(**保底 60 分钟**,全部在 ChatGPT + Obsidian 内)

| 环节 | 时长 | 动作 |
|---|---|---|
| 输入 | 25–35 min | 对项目说「**每日输入**」→ Live 里它朗读全文 + 报 5 个表达 → **搭配操练**(5 个逐个造句到说对为止)→ 口头答 3 题 |
| 热身 | 10 min | 说「**开始口语练习**」→ 错误重测 2 题 → **表达重测 5 题**(它给中文情境,你说英文)→ 领**今日任务卡**(3 个必须用出的表达) |
| 输出任务 | 20 min | 按星期轮换,**GPT 出题,你不用想话题**:一观点陈述/二角色扮演/三换受众重讲/四辩论/五案例诊断/六个人故事/日本周串讲 |
| 复盘 | 5 min | 说「**按模板复盘**」→ 复制 → Obsidian `Cmd+Shift+E` 归档 |
| 想起来时 | 随意 | Obsidian 命令面板 → `Spaced Repetition: Review flashcards from all notes` 自助过一遍表达闪卡(需先装 Spaced Repetition 插件) |

> **为什么以前撑不满时长**:整条链上只有「自由对话」没有内容供给,靠你自己想话题——话题一枯竭,练习就提前结束。换成上面的任务轮换后,每个环节的内容都由 GPT 生成,时长自然撑得住。
> 指令里已写死:**GPT 不许提前结束**,环节提前完成就追问加深,只有你说「今天到这」才停。

## 季度里程碑

### Q1(第 1–3 个月):B1 → B1+ □
- [ ] 连续打卡 ≥ 60 天
- [ ] 时态/冠词/介词类错误:从每周 ≥5 次降到 ≤1 次
- [ ] 能不间断讲 2 分钟完整故事
- [ ] 季度末测评通过 → 项目指令水平参数改为 B2

### Q2(第 4–6 个月):→ B2 □
- [ ] 就任一领域话题做 3 分钟观点陈述,逻辑连接词使用自然
- [ ] Expression Bank 积累 ≥ 100 条,且能在对话中主动用出 1/3
- [ ] Fluency、Vocabulary 稳定 ≥ 4/5
- [ ] 季度末测评通过 → 水平参数改为 B2+

### Q3(第 7–9 个月):→ B2+ □
- [ ] 能在辩论中即时反驳,使用让步-转折结构
- [ ] 新增写作线:每周一篇领域短评(在 ChatGPT 里写+改,好句进表达库)
- [ ] 开始接触真人对话(每周 1 次,语言交换或 meetup)
- [ ] 季度末测评通过 → 水平参数改为 C1-approaching

### Q4(第 10–12 个月):→ C1 冲刺 □
- [ ] 30 秒准备后能就陌生角度做 5 分钟即席演讲
- [ ] 模拟专业场景(pitch/汇报/谈判)表现稳定
- [ ] 月度模考录音对比:语速、停顿、复杂句比例显著优于 Q1
- [ ] 终期测评:对照 CEFR C1 描述逐项自评 + GPT 评估

## 提醒
- **量表随水平收紧**:每季度升级水平参数时,Grammar 的**每百词错误率**档位整体左移一档(如 B2 起:≤0.3 才算 4.5-5,0.3-0.8→4,0.8-1.5→3.5-3,以此类推),同步更新项目指令——否则量表会在后期失去分辨力。
- 断一天不算失败,断了不记才是。落后了不补课,直接从今天继续。
- 每月 1 号:对项目说「月度模考」,结果归档进 02-Daily-Logs。
