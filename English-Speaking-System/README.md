# 🎙️ 口语成长系统

你正在看的是系统的**工作区**。完整说明在仓库文档里,这一页只做导航。

## 这些文件夹是干什么的

| 文件夹 | 作用 | 你要做什么 |
|---|---|---|
| `00-Prompts/` | ChatGPT 项目指令、话题库 | 安装时把项目指令粘进 ChatGPT;卡壳时来话题库挑题 |
| `01-Templates/` | 归档模板、自动整理脚本 | 不用打开,系统自己用 |
| `02-Daily-Logs/` | 每天的练习记录 | 归档后自动出现在这里 |
| `03-Expression-Bank/` | 表达库(闪卡的数据源) | 每周把「📥 待归类」的条目挪进分类 |
| `04-Error-Patterns/` | 错误库 | 每周**大声朗读一遍**正确版本 ← 最重要的手动动作 |
| `05-Dashboard/` | 进度仪表盘 | 每周看一次趋势(用阅读模式打开) |
| `06-Roadmap/` | 一年路线图 | 每季度对照一次里程碑 |
| `07-Review/` | 复习闪卡 | 想复习时用 Spaced Repetition 插件过卡 |

## 每天怎么用

在 ChatGPT 项目里依次说三句话,然后归档一次:

1. **「每日输入」** → 文章 + 朗读 + 5 个表达 + 搭配操练 + 3 个问题
2. **「开始口语练习」** → 旧错重测 + 表达重测 + 今日任务卡 + 当天的输出任务
3. **「按模板复盘」** → 完整复盘输出
4. 点**复制** → 回到 Obsidian 按 `Cmd+Shift+E`(Windows `Ctrl+Shift+E`)→ 回车

**每月 1 号**说「月度模考」;**每季度**升级项目指令里的水平参数。
