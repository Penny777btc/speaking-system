# 07-Review 文件夹说明

| 文件 | 是什么 |
|---|---|
| `表达闪卡.md` | 由表达库自动生成的复习卡片。**不要手动编辑**,每次重建会覆盖 |
| `整理状态.md` | 「自动整理」脚本的运行记录(跑过一次后才出现),告诉你上次整理到哪天 |
| `audio/` | 表达的发音音频(仅 macOS,可选功能生成),属本地产物 |

复习方法见 [进阶文档](https://github.com/Penny777btc/speaking-system/blob/main/docs/进阶.md)。
