# 📊 进度仪表盘

> 需要 **Dataview** 插件,并在其设置中开启 **Enable JavaScript Queries**。
> 这是「看得见进步」的核心——每周日打开一次,翻回 7 天、30 天前,评分趋势一目了然。

## 评分口径速览(v3,2026-08-09 起)

| 维度 | 依据 | 权重 |
|---|---|---|
| Grammar | **每百词错误率**(错误数 ÷ 词数×100):≤0.5→4.5-5 · 0.5-1.2→4 · 1.2-2.0→3.5-3 · 2.0-3.5→3-2.5 · >3.5→<2.5;重犯旧错扣分;尝试≥3个复杂结构 +0.25;复杂结构不足 3 个时封顶 4.0 | 20% |
| Fluency | 语速(含停顿口径):≥80→5 · 70-80→4.5 · 60-70→4 · 50-60→3.5;连续讲 2 分钟 +0.25 | 30% |
| Vocabulary | 万金油词依赖度;用出表达库 chunks +0.5;词性混用扣分 | 20% |
| Communication | 结构连接词、主动澄清/追问/举例 | 30% |
| **Overall** | **= (F×0.3 + C×0.3 + G×0.2 + V×0.2) × 2,纯公式** | — |

> 口语优先权重:流利+沟通占 60%,准确度靠「错误重测闭环」提升而非总分惩罚。完整规则见 [[4-项目指令(完整版)]]。季度升级水平参数时,Grammar 错误率档位收紧一档(见 [[B1到C1路线图]])。
> **v3 关键改动**:分母从「发言分钟」换成「词数」。旧口径里语速被算了两次(Fluency 奖励、Grammar 惩罚),导致说快了无故掉分、说慢了假性涨分;换成每百词后两个轴正交。
> **搭配操练不计入评分**:操练句短、错误密集、还反复重说,算进去会同时压低 Fluency 和 Grammar。评分只取自由讨论部分,对应 `scored_time` / `word_count` / `error_rate` 三个字段。
> 2026-08-07 之前为旧量表;2026-08-09 起为 v3。跨版本分数不严格可比(v3 档位已按历史数据校准,落差应很小)。

## 总览

```dataviewjs
const pages = dv.pages('"English-Speaking-System/02-Daily-Logs"')
  .where(p => p.overall_score)
  .sort(p => p.date, 'asc');

if (pages.length === 0) {
  dv.paragraph("还没有练习记录。用 Templater 创建第一篇吧!");
} else {
  const total = pages.length;
  const minutes = pages.array().reduce((s, p) => s + (Number(p.speaking_time) || 0), 0);
  const avg = (pages.array().reduce((s, p) => s + Number(p.overall_score), 0) / total).toFixed(1);
  const last7 = pages.array().slice(-7);
  const avg7 = (last7.reduce((s, p) => s + Number(p.overall_score), 0) / last7.length).toFixed(1);
  // 连续打卡:从今天(或昨天)往回数连续有记录的天数
  // 注意用「有日期的笔记」而不是「有总分的笔记」——归档解析失败的那天也算打卡
  const allDated = dv.pages('"English-Speaking-System/02-Daily-Logs"').where(p => p.date).array();
  const days = new Set(allDated.map(p => p.date.toISODate()));
  let cursor = dv.date("today");
  if (!days.has(cursor.toISODate())) cursor = cursor.minus({ days: 1 });
  let streak = 0;
  while (days.has(cursor.toISODate())) { streak++; cursor = cursor.minus({ days: 1 }); }
  const fire = streak >= 7 ? " 🔥" : "";
  dv.paragraph(`**连续打卡:${streak} 天${fire}** · 累计:${total} 次 / ${minutes} 分钟 · 平均总分:${avg}/10 · 最近 7 次平均:${avg7}/10`);
}
```

## 四维雷达(最近 7 次平均 vs 更早)

```dataviewjs
const pages = dv.pages('"English-Speaking-System/02-Daily-Logs"')
  .where(p => p.overall_score)
  .sort(p => p.date, 'asc')
  .array();

const dims = ["fluency", "grammar", "vocabulary", "communication"];
const names = { fluency: "Fluency 流利度", grammar: "Grammar 语法", vocabulary: "Vocabulary 词汇", communication: "Communication 沟通" };

if (pages.length > 0) {
  const recent = pages.slice(-7);
  const earlier = pages.slice(0, -7);
  const avgOf = (arr, key) => {
    const vals = arr.map(p => Number(p[key])).filter(v => !isNaN(v) && v > 0);
    return vals.length === 0 ? null : vals.reduce((s, v) => s + v, 0) / vals.length;
  };

  const rows = dims.map(d => {
    const now = avgOf(recent, d);
    const before = avgOf(earlier, d);
    const bar = now === null ? "" : "▰".repeat(Math.round(now * 2)) + "▱".repeat(10 - Math.round(now * 2));
    const delta = (before === null || now === null) ? "—" :
      (now - before >= 0 ? `↑ +${(now - before).toFixed(1)}` : `↓ ${(now - before).toFixed(1)}`);
    return [names[d], now === null ? "—" : now.toFixed(1) + "/5", `<code>${bar}</code>`, delta];
  });
  dv.table(["维度", "最近 7 次平均", "", "vs 更早"], rows);
}
```

## 错误类型趋势(最近 7 次 vs 更早)

> 真正的进步信号:某类错误的「最近」列归零并保持。归零 4 周的类型,把它在 [[Error Patterns]] 里移到「已攻克」。

```dataviewjs
const pages = dv.pages('"English-Speaking-System/02-Daily-Logs"')
  .where(p => p.date)
  .sort(p => p.date, 'asc')
  .array();

const counts = {};
for (let i = 0; i < pages.length; i++) {
  const content = await dv.io.load(pages[i].file.path);
  let sec = "";
  for (const name of ["Key Corrections", "Error Log"]) {
    sec += (content.split(new RegExp("##\\s*" + name.replace(" ", "\\s+")))[1] || "").split(/\n##\s/)[0] + "\n";
  }
  // 同时兼容英文方括号 [时态] 和中文方括号 【语法:主谓一致】,冒号前的算大类
  const cats = [...sec.matchAll(/[\[【]([^\]】\n]{1,16})[\]】]/g)]
    .map(m => m[1].split(/[:：]/)[0].trim())
    .filter(c => c && c.toLowerCase() !== "category" && c !== "类型");
  const isRecent = i >= pages.length - 7;
  for (const c of cats) {
    counts[c] = counts[c] || { recent: 0, earlier: 0 };
    counts[c][isRecent ? "recent" : "earlier"]++;
  }
}
const rows = Object.entries(counts)
  .sort((a, b) => (b[1].recent + b[1].earlier) - (a[1].recent + a[1].earlier))
  .map(([cat, n]) => [cat, n.recent === 0 ? "✅ 0" : n.recent, n.earlier, n.recent + n.earlier]);
if (rows.length === 0) {
  dv.paragraph("暂无纠错记录。");
} else {
  dv.table(["错误类型", "最近 7 次", "更早", "累计"], rows);
}
```

## 表达激活率(学了到底用没用上)

> 表达库只增不减,光看条数不知道吸收了多少。这里看的是**自发用出**——没被提示就说出来的次数。
> 数据来自每天复盘的 `## Expressions Used`。自发累计 2 次 = 毕业。

```dataviewjs
const pages = dv.pages('"English-Speaking-System/02-Daily-Logs"')
  .where(p => p.date).sort(p => p.date, 'asc').array();
const used = {};          // 表达 -> 自发次数
let cardHit = 0, cardTotal = 0, days = 0;
for (const p of pages) {
  const c = await dv.io.load(p.file.path);
  const sec = (c.split(/##\s*Expressions Used/)[1] || "").split(/\n##\s/)[0];
  if (!sec.trim()) continue;
  days++;
  const spont = (sec.match(/自发用出[:：](.*)/) || [])[1] || "";
  for (const raw of spont.split(/[,，、;；]/)) {
    const e = raw.trim().replace(/^-\s*/, "");
    if (e && e.length > 1 && !/^(无|None|none)$/.test(e)) used[e] = (used[e] || 0) + 1;
  }
  const card = (sec.match(/任务卡[^\d]*(\d+)\s*\/\s*(\d+)/) || []);
  if (card.length) { cardHit += Number(card[1]); cardTotal += Number(card[2]); }
}
const entries = Object.entries(used).sort((a, b) => b[1] - a[1]);
const graduated = entries.filter(([, n]) => n >= 2);
// 表达库总条目(作为分母参考)
const bank = await dv.io.load("English-Speaking-System/03-Expression-Bank/Expression Bank.md");
const bankCount = (bank.match(/^- /gm) || []).length;
if (days === 0) {
  dv.paragraph("还没有 `## Expressions Used` 数据——这一节是 2026-08-10 起的新格式,明天第一次复盘后就会有。");
} else {
  const rate = bankCount ? (entries.length / bankCount * 100).toFixed(0) : "—";
  dv.paragraph(`**激活率:${entries.length}/${bankCount} = ${rate}%** · 已毕业(自发≥2 次):${graduated.length} 条 · 任务卡命中:${cardHit}/${cardTotal} · 统计天数:${days}`);
  if (entries.length) {
    dv.table(["表达", "自发次数", "状态"],
      entries.slice(0, 15).map(([e, n]) => [e, n, n >= 2 ? "🎓 已毕业" : "🔁 队列中"]));
  }
}
```

## 每百词错误率趋势(最诚实的进步信号)

> 错误率 = 错误数 ÷ 词数 × 100。**这条线跌就是真进步**,不受话题难度、总分合成、也不受语速干扰——这正是它换掉旧「÷发言分钟」口径的原因(旧口径里说快了会无故变差)。
> 优先读 frontmatter 的 `error_rate`(GPT 算的,已排除搭配操练);没有该字段时用 `word_count` 现算;两者都没有的旧笔记标为「旧口径」,不参与均线。
> 注:2026-08-03 下午之前的记录没有 Error Log,错误数偏低,数值失真。

```dataviewjs
const pages = dv.pages('"English-Speaking-System/02-Daily-Logs"')
  .where(p => p.date)
  .sort(p => p.date, 'asc')
  .array();
const rows = [];
const series = [];
for (const p of pages) {
  const c = await dv.io.load(p.file.path);
  let sec = "";
  for (const name of ["Key Corrections", "Error Log"]) {
    sec += (c.split(new RegExp("##\\s*" + name.replace(" ", "\\s+")))[1] || "").split(/\n##\s/)[0] + "\n";
  }
  const n = (sec.match(/❌/g) || []).length;
  const words = Number(p.word_count) || 0;
  let rate = Number(p.error_rate) || 0;
  if (!rate && words) rate = (n / words) * 100;
  if (rate) {
    series.push(rate);
    const avg7 = series.slice(-7).reduce((s, v) => s + v, 0) / Math.min(series.length, 7);
    const bar = "▉".repeat(Math.max(1, Math.min(24, Math.round(rate * 5))));
    rows.push([p.file.link, n, words || "—", rate.toFixed(1), avg7.toFixed(1), `<code>${bar}</code>`]);
  } else {
    const t = Number(p.speaking_time) || 0;
    rows.push([p.file.link, n, "—", t ? `旧口径 ${(n / t).toFixed(2)}/min` : "—", "—", ""]);
  }
}
if (rows.length === 0) { dv.paragraph("暂无数据。"); } else {
  dv.table(["日期", "错误数", "评分词数", "每百词错误率", "7次均线", "趋势(条越短越好)"], rows);
}
```

## 怎么读这个仪表盘

- **总分曲线往上走** → 系统在起作用,继续
- **某一维度长期垫底**(比如 Grammar)→ 下周的 Speaking Goal 就针对它,并检查 [[Error Patterns]] 里对应类别是否在变少
- **连续几天没有记录** → 别补,直接从今天重新开始。断一天不算失败,断了不记才是
