# 可移植性与体验边界

## 两种复刻

- **Penny 同款**:使用 `assets/profiles/penny.json`,复制公开的参数、触发词、训练节奏、话题库、路线图和 Obsidian 结构。
- **完整状态迁移**:除 Penny 同款外,再导入用户明确提供的表达库和错误库。私人 ChatGPT 对话、项目记忆和语音记录不会随 Skill 自动迁移。

## 各运行环境

- **ChatGPT/Codex 能执行脚本并提供下载文件**:运行 `scripts/configure.py`,交付生成的 ZIP 与项目指令。
- **Codex 能访问本机 Obsidian**:得到用户明确授权和仓库路径后,可把配置目录复制进仓库;安装社区插件前再次确认。
- **ChatGPT Web 无本机文件权限**:只生成并交付 ZIP,不要声称已修改用户电脑或 Obsidian。
- **仅把 ZIP 作为聊天附件**:Skill 的作用域通常限于该聊天或项目;需要跨对话长期可用时,把 Skill 安装到支持的 Skills/Plugins 环境。

## 不能自动复制的状态

- ChatGPT 项目历史和平台记忆
- 语音转录历史
- 用户未提供的 Obsidian 日志、表达库、错误库
- 操作系统权限、Obsidian 社区插件信任和账号登录状态

对这些状态保持透明。用“功能等价”描述成功部署,不要承诺账号级状态完全克隆。
