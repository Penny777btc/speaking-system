# 🗺️ B1 → C1 一年路线图

> 开始日期:2026-08-02 · 目标:2027-08 达到 C1
> **每季度末对项目说「月度模考」做一次测评,通过了才升级下一季度**(同时把 ChatGPT 项目指令里的「当前水平参数」调高一级)。

## 每日节奏(约 50–75 分钟,全部在 ChatGPT + Obsidian 内)

| 环节 | 时长 | 动作 |
|---|---|---|
| 输入 | 20–30 min | 对项目说「**每日输入**」→ 读短文 + 朗读听一遍 → Live 里它会朗读全文+报表达,然后口头答题 |
| 口语 | 15 min | 同一会话说「**开始口语练习**」(同一个 Live 会话接着说)→ 热身重测 → 自由对话 |
| 复盘 | 5 min | 说「**按模板复盘**」→ 复制 → Obsidian `Cmd+Shift+E` 归档 |
| 周日 | +10 min | 金句进表达库、错误进错误库、朗读错误库、看仪表盘 |

## 季度里程碑

### Q1:2026-08 → 2026-10(B1 → B1+)□
- [ ] 连续打卡 ≥ 60 天
- [ ] 时态/冠词/介词类错误:从每周 ≥5 次降到 ≤1 次
- [ ] 能不间断讲 2 分钟完整故事
- [ ] 季度末测评通过 → 项目指令水平参数改为 B2

### Q2:2026-11 → 2027-01(→ B2)□
- [ ] 就任一领域话题做 3 分钟观点陈述,逻辑连接词使用自然
- [ ] Expression Bank 积累 ≥ 100 条,且能在对话中主动用出 1/3
- [ ] Fluency、Vocabulary 稳定 ≥ 4/5
- [ ] 季度末测评通过 → 水平参数改为 B2+

### Q3:2027-02 → 2027-04(→ B2+)□
- [ ] 能在辩论中即时反驳,使用让步-转折结构
- [ ] 新增写作线:每周一篇领域短评(在 ChatGPT 里写+改,好句进表达库)
- [ ] 开始接触真人对话(每周 1 次,语言交换或 meetup)
- [ ] 季度末测评通过 → 水平参数改为 C1-approaching

### Q4:2027-05 → 2027-08(→ C1 冲刺)□
- [ ] 30 秒准备后能就陌生角度做 5 分钟即席演讲
- [ ] 模拟专业场景(pitch/汇报/谈判)表现稳定
- [ ] 月度模考录音对比:语速、停顿、复杂句比例显著优于 Q1
- [ ] 终期测评:对照 CEFR C1 描述逐项自评 + GPT 评估

## 提醒
- **量表随水平收紧**:每季度升级水平参数时,Grammar 错误密度档位整体左移一档(如 B2 起:≤0.2/min 才算 4.5-5,0.2-0.5→4,以此类推),同步更新项目指令——否则量表会在后期失去分辨力。
- 断一天不算失败,断了不记才是。落后了不补课,直接从今天继续。
- 每月 1 号:对项目说「月度模考」,结果归档进 02-Daily-Logs。
