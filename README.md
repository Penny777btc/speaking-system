# 🎙️ Speaking System — 用 ChatGPT 语音 + Obsidian 练出一口英语

> 光练不记,等于白练。这套系统把每次开口变成可追踪的成长记录。
> 每天 30–60 分钟,一年从 B1 到 C1。不用写代码,15 分钟装好。

## 它长什么样

每天对着 ChatGPT 语音说四句话,系统自动完成剩下的一切:

| 你说 | 它做 |
|---|---|
| 「每日输入」 | 按你的兴趣领域生成短文并朗读,教你 5 个地道表达,逐个陪你操练 |
| 「开始口语练习」 | 先重测你之前犯过的错,再给你结构化的输出任务(观点陈述/角色扮演/辩论…) |
| 「按模板复盘」 | 输出当天全部错误清单、评分(证据锚定,不凭感觉)、明天的训练目标 |
| *(复制→Obsidian 按快捷键)* | 自动归档:评分入库、仪表盘画曲线、错误进错误库等着被你消灭 |

**打开 Obsidian 时还会自动**:把新表达和新错误归集进两个库、重建带复习进度的闪卡(安装第四步打开一个开关即可,之后零操作)。

👉 完整的手动/自动边界见 **[docs/日常流程.md](docs/日常流程.md)**

## 使用前 vs 使用后

| | ❌ 之前 | ✅ 之后 |
|---|---|---|
| 练完 | 对话再爽,下课就忘 | 每天沉淀一篇结构化记录 |
| 纠错 | 今天纠正,明天照犯 | 错误进库 → 隔天热身重测 → 直到「已攻克」 |
| 表达 | 学过就丢 | 表达进库 → 对话里自发用出 2 次才「毕业」 |
| 进步 | 全凭感觉 | 打卡天数、每百词错误率、评分曲线,一眼可见 |

## 开始使用:先选一条路

### 🤖 A. 有本地 AI 助手(Codex / Claude Code / Cursor)——约 5 分钟

对它粘贴这句话:

```
读取 https://raw.githubusercontent.com/Penny777btc/speaking-system/main/AGENT-SETUP.md 并严格照做,帮我完成安装
```

它会问你 5 个问题,然后 90 秒内装完插件、写好配置、把 ChatGPT 指令按你的领域填好放进剪贴板。

📖 **完整流程 → [docs/自动安装.md](docs/自动安装.md)**

### 🖱️ B. 没有 AI 助手——约 15 分钟

[📥 下载本仓库](https://github.com/Penny777btc/speaking-system/archive/refs/heads/main.zip) → 拖文件夹进 Obsidian → 装 2 个插件 → 配 ChatGPT。每步都有自检点。

📖 **完整流程 → [docs/手动安装.md](docs/手动安装.md)**

### 两条路差在哪

| 环节 | 🤖 A. 有 AI 助手 | 🖱️ B. 手动 |
|---|---|---|
| 下载、解压、放文件 | AI 干 | 你干(注意别用 `unzip`,中文文件名会失败) |
| 装 Templater + Dataview | AI 直接放进插件文件夹 | 你去插件市场搜索安装 |
| 关闭「安全模式」 | **不需要** | **需要**(否则进不了插件市场) |
| 设模板目录、绑快捷键、开 Dataview 的 JS | AI 写配置(**合并式,不覆盖你已有的设置**) | 你在设置界面点 |
| 把指令改成你的领域和水平 | AI 按你的回答填好,放进剪贴板 | 你在 6000 字里自己改三处 |
| 配「每晚 AI 自动整理」(可选) | AI 可以顺便配好 | 需要自己照 [文档](docs/AI每晚自动整理.md) 配 |
| **打开「自动整理」开关** | 🖐️ 都要你自己点 | 🖐️ 都要你自己点 |
| **建 ChatGPT 项目并粘贴指令** | 🖐️ 都要你自己做 | 🖐️ 都要你自己做 |
| **耗时** | 约 5 分钟(其中 90 秒只是看着) | 约 15 分钟 |
| **装出来的系统** | **完全一样** | **完全一样** |

最后两行是重点:**无论走哪条路,有两件事必须你亲手做**——

1. **打开 Obsidian 的「自动整理」开关** — Templater 把这类危险开关存在设备本地,写配置文件永远无效。这是防止恶意模板自动执行代码的安全设计
2. **建 ChatGPT 项目并粘贴指令**(2 分钟,见 [docs/配置ChatGPT项目.md](docs/配置ChatGPT项目.md))— 项目是云端功能,没有公开 API,任何工具都代劳不了

装完先跑一遍 **[docs/安装验收.md](docs/安装验收.md)**(3 分钟,用测试数据确认整条链路通了)。

装好之后怎么用 → **[docs/日常流程.md](docs/日常流程.md)**;遇到问题 → [docs/常见问题.md](docs/常见问题.md)

## 这套系统的三个设计原则

1. **证据锚定评分**:Grammar 看每百词错误率、Fluency 看语速,总分是公式算的——AI 不许凭感觉打分,所以曲线可信
2. **错误和表达都是闭环**:错误要重测通过才算攻克,表达要自发用出才算学会——没有「学过就算学会」
3. **自动化搬运,人工朗读**:记录归档全自动,唯一留给你的动作是每天开口和大声朗读——那是唯一长肌肉的部分
