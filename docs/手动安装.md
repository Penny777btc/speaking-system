# 手动安装(约 15 分钟)

> 不需要任何 AI 工具,全程点鼠标。
> **有 Codex / Claude Code?** 可以走 [自动安装](自动安装.md),约 5 分钟,装出来完全一样。

---

## 全流程速览

```
下载并解压(1 分钟)
   ↓
把文件夹拖进 Obsidian(2 分钟)
   ↓
装 2 个插件并配置(6 分钟)
   │  Templater(归档要用)+ Dataview(仪表盘要用)
   │  设模板目录 → 绑快捷键 → 开 Dataview 的 JS 开关
   ↓
打开「自动整理」开关(1 分钟,建议)
   ↓
配置 ChatGPT 项目(3 分钟)
   ↓
验收 → 开练
```

---

## 你需要准备

| | 说明 |
|---|---|
| **Obsidian** | 免费,[obsidian.md](https://obsidian.md) 下载(电脑版) |
| **ChatGPT 账号** | 免费版可用;Plus 的语音体验更好 |

---

## 第 1 步:下载并放进 Obsidian(3 分钟)

1. **下载**:[点这里下载仓库 ZIP](https://github.com/Penny777btc/speaking-system/archive/refs/heads/main.zip)
2. **解压**:双击即可
   > ⚠️ **macOS 命令行用户注意**:别用 `unzip`,它解不了压缩包里的中文文件名(会报 Illegal byte sequence,核心文件全部失败)。用 `ditto -x -k 文件.zip 目标目录`,或者干脆双击。
3. **打开 Obsidian**,创建一个新仓库,或用你现有的仓库
4. 在访达/资源管理器里,把解压出来的 **`English-Speaking-System` 整个文件夹**拖进你的 Obsidian 仓库根目录
5. 回到 Obsidian,左侧文件树里应该能看到 `English-Speaking-System` 和它的 8 个子文件夹

> 解压出来的其他东西(`docs/`、`scripts/`、`README.md`)不用拖进去,但**别删**——`scripts/` 里的闪卡音频脚本以后可能用得上。建议把整个解压目录留在一个固定位置。

---

## 第 2 步:装两个插件并配置(6 分钟)

### 装

1. Obsidian 设置 → **第三方插件** → 关闭「**安全模式 / 受限模式**」
   > 这一步只有手动安装需要——AI Agent 是直接把插件放进文件夹的,不走插件市场。
2. 点「**浏览**」进入社区插件市场,搜索并**安装 + 启用**这两个:

| 插件 | 干什么 | 不装会怎样 |
|---|---|---|
| **Templater** | 一键归档(`Cmd+Shift+E`)、自动整理 | 无法归档,评分进不了笔记 |
| **Dataview** | 仪表盘的所有统计查询 | 仪表盘只显示一堆代码 |

### 配

3. **Dataview 设置** → 打开 **Enable JavaScript Queries**
   > 仪表盘用的是 dataviewjs,不开这个只有部分表格能显示。
4. **Templater 设置** → **Template folder location** 填:
   `English-Speaking-System/01-Templates`
5. Obsidian 设置 → **快捷键** → 搜「**Templater: Create new note from template**」→ 绑定 `Cmd+Shift+E`(Windows / Linux 用 `Ctrl+Shift+E`)

### ✅ 自检

按一下 `Cmd+Shift+E`,应该弹出模板选择框,里面有「**English Study 剪贴板归档**」。按 Esc 关掉。

---

## 第 3 步:打开「自动整理」开关(1 分钟,强烈建议)

不开也能用,但开了之后**每次打开 Obsidian**,系统会自动把新表达和新错误归集进两个库、重建复习闪卡——否则这些要你每周手动做。

1. Obsidian 设置 → 左栏找到 **Templater**
2. 往下滚到 **Startup templates** 区
3. 打开 **Enable startup templates** → 弹出风险确认框 → **勾选「I understand the risks」** → 点 Enable
4. 下面的 **Startup templates** 列表点 ➕,填:
   `English-Speaking-System/01-Templates/自动整理.md`
5. **重启 Obsidian**

> ⚠️ 这个开关存的是**本机设置**——每台设备都要单独开一次,而且只能在这个界面点(改配置文件无效)。这是防止恶意模板自动执行代码的安全设计。

### ✅ 自检

重启后右上角应弹出一个「自动整理:…」的通知。**第一天还没有练习日志时不会弹,这是正常的。**

---

## 第 4 步:配置 ChatGPT 项目(3 分钟)

1. 打开 [ChatGPT-指令.md](ChatGPT-指令.md),复制代码块里的整段指令(约 6000 字,很长是正常的)
2. **粘贴前先改三处**:

| 改什么 | 在哪 | 换成 |
|---|---|---|
| 兴趣领域 | 第 1 行(全文出现 3 次,都要改) | 你真正关心的 3–4 个领域 |
| 水平参数 | 第 2 行 `【当前水平参数:B1+】` | 你的 CEFR 等级,不确定就留 B1+ |
| 目标 | 第 1 行末 | 你的目标和期限 |

3. 在 ChatGPT 里**新建项目**,把指令贴进项目的「编辑指令」里保存

**完整步骤和踩坑说明 → [配置 ChatGPT 项目](配置ChatGPT项目.md)**

> 那一页最重要的一句:**必须建「项目」,不能贴进普通对话或账号的自定义指令**——贴错地方会导致触发词失效、复习链断掉,而且不会有任何报错。

---

## ✅ 验收:三个都对就装好了

| 测试 | 应该看到 |
|---|---|
| Obsidian 里按 `Cmd+Shift+E` | 弹出模板选择框,里面有「English Study 剪贴板归档」 |
| 打开 `05-Dashboard/进度仪表盘.md` | 显示表格(不是一堆代码),内容是「还没有练习记录」 |
| ChatGPT 项目里发「每日输入」 | 一篇你所选领域的英文短文 + 5 个加粗表达 + 开始让你造句 |

---

## 你的第一天

1. 在 ChatGPT 项目里打开 Live 语音,说 **「每日输入」** → 听文章、做搭配操练、回答问题
2. 接着说 **「开始口语练习」** → 做当天的输出任务
3. 练完**退出语音、打字**发 **「按模板复盘」** → 点复盘消息的**复制**按钮
4. 回 Obsidian 按 `Cmd+Shift+E` → 回车 → 笔记自动建好,评分自动入库
5. 打开 `05-Dashboard/进度仪表盘.md` → 看到你的第一条记录

之后每天重复这 4 个动作。完整说明见 **[日常流程](日常流程.md)**。

## 安装时可能卡住的地方

| 现象 | 原因与解法 |
|---|---|
| 解压后文件名是乱码 / 文件缺失 | 用了 `unzip`。改用双击解压,或 `ditto -x -k` |
| 插件市场搜不到插件 | 「安全模式 / 受限模式」没关 |
| 按 `Cmd+Shift+E` 没反应 | 快捷键没绑成功,或该键位被占用;去设置 → 快捷键搜 Templater 检查 |
| 模板选择框是空的 | Templater 的 Template folder location 填错了,检查是否为 `English-Speaking-System/01-Templates` |
| 仪表盘显示一堆代码 | Dataview 的 **Enable JavaScript Queries** 没开 |
| 重启后没有「自动整理」通知 | 第 3 步的总闸没拨;或者第一天还没有日志(正常) |
| 在项目里发触发词没反应 | 你可能在项目**外面**;或指令没保存;或保存后没**新开对话** |

使用中的问题见 [常见问题](常见问题.md);想了解系统内部原理见 [维护知识库](维护知识库.md)。
