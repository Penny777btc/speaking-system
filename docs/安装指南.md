# 手动安装指南(约 15 分钟)

> 不需要任何 AI 工具。有 Codex / Claude Code 的话可以走 [自动安装](自动安装.md),约 5 分钟。

> 三步:把文件夹拖进 Obsidian → 装两个插件 → 给 ChatGPT 贴一段指令。全程不需要写代码。

## 你需要准备

- **Obsidian**(免费,obsidian.md 下载,电脑版)
- **ChatGPT 账号**(免费版可用;Plus 的语音体验更好)

## 第一步:装入 Obsidian(5 分钟)

1. 打开 Obsidian → 创建一个新仓库(或用你现有的仓库)
2. 把本仓库的 **English-Speaking-System 整个文件夹**(绿色 Code 按钮 → Download ZIP,**双击解压**;命令行用户请用 `ditto -x -k`,macOS 的 unzip 解不了中文文件名)拖进你仓库的根目录(在访达/资源管理器里拖即可)
3. 回到 Obsidian,左侧应能看到 English-Speaking-System 及其子文件夹

## 第二步:装两个插件(5 分钟)

1. Obsidian 设置 → **第三方插件** → 关闭「安全模式/受限模式」(只有手动装才需要这一步——用 AI Agent 安装时插件是直接放进文件夹的,不走插件市场)
2. 点「浏览」社区插件市场,搜索并安装+启用:
   - **Templater**(一键归档靠它)
   - **Dataview**(仪表盘靠它;装好后进它的设置,打开 **Enable JavaScript Queries**)
3. 进 Templater 设置:
   - Template folder location 填:`English-Speaking-System/01-Templates`
4. 设置 → 快捷键 → 搜「Templater: Create new note from template」→ 绑定 `Cmd+Shift+E`(Windows 用 `Ctrl+Shift+E`)

✅ 自检:按一下快捷键,应弹出模板选择框,里面有「English Study 剪贴板归档」。

## 第三步:配置 ChatGPT 项目(3 分钟)

打开 [ChatGPT-指令.md](ChatGPT-指令.md) 复制整段指令,按你的情况改三处(兴趣领域、水平参数、目标),然后建项目并粘贴。

**完整步骤和踩坑说明 → [配置 ChatGPT 项目](配置ChatGPT项目.md)**

那一页讲清楚了:**为什么必须建「项目」而不能贴进普通对话**(最容易踩的坑)、界面上具体点哪里、以及两个验证测试。

## 第四步:打开「自动整理」开关(1 分钟,强烈建议)

不开也能用,但开了之后**每次打开 Obsidian**,系统会自动把新表达和新错误归集进两个库、重建复习闪卡——否则这些要你手动整理。

1. Obsidian 设置 → **Templater**(在左栏「第三方插件」区)
2. 往下滚到 **Startup templates** 区
3. 打开 **Enable startup templates** 开关 → 弹出风险确认框 → **勾选「I understand the risks」** → 点 Enable
   > ⚠️ 这个开关存的是本机设置,**每台设备都要单独打开一次**;而且只能在这个界面点,改配置文件没用。
4. 在下面的 **Startup templates** 列表里点 ➕,填:`English-Speaking-System/01-Templates/自动整理.md`
5. 重启 Obsidian

✅ 自检:重启后右上角应弹出一个「自动整理:…」的通知(第一天还没有日志时不会弹,属正常)。

## 第五步:跑通第一个循环(当天练习时)

1. 在项目里开语音(或打字),说 **「每日输入」** → 读/听文章、回答问题
2. 说 **「开始口语练习」** → 自由对话
3. 练完说 **「按模板复盘」** → 点复盘消息的**复制**按钮
4. 回 Obsidian 按 `Cmd+Shift+E` → 回车 → 笔记自动建好,评分自动写进属性
5. 打开 `05-Dashboard/进度仪表盘.md` → 应看到你的第一条记录和评分

## 装完之后怎么用

完整的日常流程见 **[日常流程.md](日常流程.md)** —— 那一页把「哪些你做、哪些系统自动做」写得很清楚。速览:

- **每天 4 个动作**:说「每日输入」→ 说「开始口语练习」→ 说「按模板复盘」→ 复制 + `Cmd+Shift+E` 归档
- **打开 Obsidian 时自动**:整理表达/错误、重建复习闪卡(需启用启动脚本,见 [进阶.md](进阶.md))
- **每周 5 分钟**:把待归类条目挪进分类 + **大声朗读错误库**(唯一不该自动化的动作)
- **每月 1 号**:说「月度模考」;**每季度**:升级水平参数

## 常见问题(踩坑速查)

| 现象 | 原因与解法 |
|---|---|
| 说触发词没反应 | 你不在项目里,或改完指令没**开新会话**(改指令必开新会话) |
| 语音朗读文章太短/中途停 | 对它说 "Too short, add two more paragraphs" / "Keep going" |
| 语音突然说中文 | 说一句 "English only, please" |
| 归档后评分是空的 | 复制时格式被拍平了,正常现象,手动把分数填进笔记属性即可 |
| 仪表盘显示的是代码不是图表 | Dataview 没装好,或没开 Enable JavaScript Queries |
| 手机也想用 | 把仓库放进 iCloud 的 Obsidian 文件夹,手机装 Obsidian 即可同步 |

更深的原理和维护知识见 [维护知识库](维护知识库.md)(写给 AI 维护者,但人也能读)。
