# 自动安装(有 AI Agent,约 5 分钟)

> 让你的本地 AI 助手替你装完 Obsidian 侧的一切。你只需回答几个问题、批准它执行,最后自己配一次 ChatGPT。
> **没有 AI 助手?** 走 [手动安装](手动安装.md),15 分钟,装出来的东西完全一样。

---

## 全流程速览

```
你粘贴一句话
   ↓
Agent 问你 5 个问题 ──── 你回答(约 30 秒)
   ↓
Agent 干活(约 90 秒) ── 你批准执行,看着就行
   │  下载文件 → 装 2 个插件 → 写配置 → 自检
   │  按你的领域填好 ChatGPT 指令 → 放进剪贴板
   │  (可选)配好每晚自动整理
   ↓
你做最后一件事(2 分钟)── 在 ChatGPT 里建项目、粘贴指令
   ↓
开练
```

**总计约 5 分钟,其中 90 秒你只是在旁边看着。**

---

## 你需要什么

| | 说明 |
|---|---|
| **Obsidian** | 免费,[obsidian.md](https://obsidian.md) 下载 |
| **ChatGPT 账号** | 免费版可用;Plus 的语音体验更好 |
| **一个有本地权限的 AI 助手** | Codex、Claude Code、Cursor Agent 都行 |

> ⚠️ 关键是它能**在你电脑上执行命令和写文件**。网页版 ChatGPT / Claude 不行——它们碰不到你的磁盘。

---

## 第 1 步:让 Agent 干活

### 通用方式(任何 Agent)

打开你的 AI 助手,粘贴:

```
读取 https://raw.githubusercontent.com/Penny777btc/speaking-system/main/AGENT-SETUP.md 并严格照做,帮我完成安装
```

### Codex CLI 版(无人值守)

装了 ChatGPT 桌面版就自带 Codex CLI(藏在应用包里,不在 PATH):

```bash
/Applications/ChatGPT.app/Contents/Resources/codex exec -C "<你的 Obsidian 仓库路径>" \
  --approve-for-me --skip-git-repo-check \
  -c 'sandbox_workspace_write.network_access=true' \
  "读取 https://raw.githubusercontent.com/Penny777btc/speaking-system/main/AGENT-SETUP.md 并严格照做,帮我完成安装。仓库路径就是当前工作目录。"
```

> 三个参数坑:`--approve-for-me` 和 `-s/--sandbox` 互斥;非 git 目录必须加 `--skip-git-repo-check`;联网要显式开 `network_access=true`。

---

## 第 2 步:回答它的五个问题

先想好答案会快很多:

| 它问什么 | 你怎么答 |
|---|---|
| **① Obsidian 仓库的绝对路径** | 打开 Obsidian → 鼠标悬停左下角仓库名可看到路径。也可以让它新建一个空文件夹当新仓库 |
| **② 想练哪些领域**(3–4 个) | 你真正关心的话题,系统每天从里面轮换选题写文章。例:AI、商业模式、创业、个人成长 / 医学、科研、职场沟通 |
| **③ 当前英语水平** | CEFR 等级(A2 / B1 / B1+ / B2 / B2+)。不确定就说 **B1+**,以后每季度自己升 |
| **④ 要不要装复习闪卡插件** | 可选,不装也能用,以后随时能加 |
| **⑤ 要不要配「每晚 AI 自动整理」** | 可选,**默认不配**。见下方说明 |

### 关于第 ⑤ 个问题

| | 配了 | 不配 |
|---|---|---|
| 每天的表达和错误 | AI 每晚自动归类进库、合并相似错误、统计「学了用没用上」 | 打开 Obsidian 时脚本机械搬进「📥 待归类」区,分类你自己挪(每周约 5 分钟) |
| 额外好处 | 重建闪卡 + 发音音频、8 项数据体检、每日简报 | — |
| 代价 | **每晚在后台调用一次 AI**(消耗你的额度),并在你电脑上留一个定时任务 | 无 |

**不确定就先说「以后再说」**——练几天确认自己会坚持后,随时可以照 [AI 每晚自动整理](AI每晚自动整理.md) 补配。

---

## 第 3 步:批准它执行(约 90 秒)

它会请求权限执行命令,批准即可。这 90 秒里它在做:

- 下载系统文件到你的 Obsidian 仓库,并在 `~/speaking-system` 留一份仓库副本(闪卡脚本要用)
- 装 **Templater** 和 **Dataview**(直接放进插件文件夹,不走插件市场,所以**你不需要关闭「安全模式」**)
- 写好模板目录、Dataview 的 JS 开关、`Cmd+Shift+E` 快捷键
- **合并式写入**——你仓库里已有的插件、已绑的快捷键,一个都不会被覆盖
- 跑一遍文件级自检
- **按你的领域和水平把那段 6000 字的 ChatGPT 指令填好,放进剪贴板**
- 把浏览器打开到 ChatGPT 项目页
- (如果你选了 ⑤)配好每晚 22:15 的定时任务,并告诉你怎么卸载

---

## 第 4 步:打开「自动整理」开关(1 分钟)

> ⚠️ **如果第 ⑤ 题你选了「配置每晚 AI 自动整理」,跳过这一步**——两者互斥,都开的话表达会卡在「待归类」区拿不到智能分类。

这是 agent **唯一无法替你写的设置**:Templater 把「自动执行模板」这类危险开关存在**设备本地**,不在配置文件里。这是它的安全设计——防止有人给你一个恶意模板 + 配置文件,打开 Obsidian 就自动跑代码。这个限制保护的正是你。

1. Obsidian 设置 → 左栏找到 **Templater**
2. 往下滚到 **Startup templates** 区
3. 打开 **Enable startup templates** → 弹出风险框 → **勾选「I understand the risks」** → Enable
4. 下面的列表点 ➕,填 `English-Speaking-System/01-Templates/自动整理.md`
5. 重启 Obsidian

> 这个开关**每台设备单独存**。以后在另一台电脑打开同一个仓库,要再点一次。

---

## 第 5 步:配置 ChatGPT 项目(2 分钟)

指令已经按你的参数填好、就在剪贴板里,浏览器也已打开到项目页。

**完整步骤 → [配置 ChatGPT 项目](配置ChatGPT项目.md)**

那一页最重要的一句话:**必须建「项目」,不能贴进普通对话或账号的自定义指令**——贴错地方会导致触发词失效、复习链断掉,而且不会有任何报错。

## 出问题了

| 现象 | 怎么办 |
|---|---|
| Agent 说没有网络权限 / 下载失败 | 给它开网络访问;GitHub API 每小时限流 60 次,失败就等会儿再试 |
| Agent 说目标位置已存在同名文件夹 | 它在保护你已有的数据(设计如此)。确认是不是装过一次,或换个仓库 |
| 按 `Cmd+Shift+E` 没反应 | 重启 Obsidian;还不行就去设置 → 快捷键搜 Templater 确认绑定 |
| 仪表盘显示代码不显示表格 | Dataview 的 **Enable JavaScript Queries** 没开 |
| 打开 Obsidian 没有「自动整理」通知 | 第 4 步的总闸没拨;第一天还没有日志时不弹通知也正常 |
| 想取消每晚定时任务 | `launchctl unload ~/Library/LaunchAgents/com.speakingsystem.nightly.plist && rm ~/Library/LaunchAgents/com.speakingsystem.nightly.plist` |

更多见 [常见问题](常见问题.md)。想让 AI 帮你排障,把 [维护知识库](维护知识库.md) 给它——里面有全部已知故障和排查信号。
