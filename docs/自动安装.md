# 自动安装(有 AI Agent,约 5 分钟)

> 让你的本地 AI 助手替你完成 Obsidian 侧的全部安装。你只需要回答几个问题、批准它的操作,最后自己做两件它做不了的事。
> 没有 AI 助手?看 [手动安装指南](安装指南.md),15 分钟同样能装好,功能完全一样。

---

## 你需要什么

- **Obsidian**(免费,[obsidian.md](https://obsidian.md) 下载)
- **ChatGPT 账号**(免费版可用;Plus 的语音体验更好)
- **一个有本地权限的 AI 助手**——Codex、Claude Code、Cursor Agent 都行
  > 关键是它能在你电脑上执行命令和写文件。**网页版 ChatGPT / Claude 不行**,它们碰不到你的磁盘。

---

## 第 1 步:让 Agent 干活(约 90 秒)

### 通用方式(任何 Agent)

打开你的 AI 助手,粘贴这句话:

```
读取 https://raw.githubusercontent.com/Penny777btc/speaking-system/main/AGENT-SETUP.md 并严格照做,帮我完成安装
```

### Codex CLI 无人值守版

装了 ChatGPT 桌面版就自带 Codex CLI(藏在应用包里,不在 PATH):

```bash
/Applications/ChatGPT.app/Contents/Resources/codex exec -C "<你的 Obsidian 仓库路径>" \
  --approve-for-me --skip-git-repo-check \
  -c 'sandbox_workspace_write.network_access=true' \
  "读取 https://raw.githubusercontent.com/Penny777btc/speaking-system/main/AGENT-SETUP.md 并严格照做,帮我完成安装。仓库路径就是当前工作目录。"
```

> 三个容易踩的参数坑:`--approve-for-me` 和 `-s/--sandbox` 互斥;目标目录不是 git 仓库时必须加 `--skip-git-repo-check`;联网要显式开 `network_access=true`。

---

## Agent 会问你四个问题

先想好答案,回答起来更快:

| 问题 | 怎么答 |
|---|---|
| **Obsidian 仓库的绝对路径** | 打开 Obsidian → 左下角仓库名上悬停可看到路径。也可以让它新建一个空文件夹当新仓库 |
| **想练哪些领域**(3–4 个) | 你真正关心的话题,系统每天从里面轮换选题写文章。例:AI、商业模式、创业、个人成长 / 医学、科研、职场沟通 |
| **当前英语水平** | CEFR 等级(A2 / B1 / B1+ / B2 / B2+),不确定就说 B1+,以后每季度自己升 |
| **要不要装复习闪卡插件** | 可选。不装也能用,以后随时能加 |

回答完之后,它会请求执行命令的权限——**批准即可**,它做的都是下载文件和写配置。

## Agent 在这 90 秒里做了什么

- 下载系统文件到你的 Obsidian 仓库
- 装 Templater 和 Dataview 两个插件(直接放进插件文件夹,不走插件市场)
- 写好模板目录、Dataview 的 JS 开关、`Cmd+Shift+E` 快捷键
- **合并式写入**:如果你的仓库已经装过别的插件、绑过别的快捷键,一个都不会被覆盖
- 跑一遍文件级自检
- **按你的领域和水平把 ChatGPT 指令填好,放进剪贴板**
- 帮你把浏览器打开到 ChatGPT 项目页

---

## 第 2 步:打开「自动整理」开关(1 分钟)

这是**唯一一个 agent 无法替你写的设置**。

Templater 把「自动执行模板」这类危险开关存在**设备本地**,不在配置文件里——这是它的安全设计,防止有人给你一个恶意模板 + 配置文件,打开 Obsidian 就自动跑代码。换句话说,这个限制保护的正是你。

**操作:**

1. Obsidian 设置 → 左栏找到 **Templater**
2. 往下滚到 **Startup templates** 区
3. 打开 **Enable startup templates** → 弹出风险确认框 → **勾选「I understand the risks」** → 点 Enable
4. 下面的 **Startup templates** 列表点 ➕,填:
   `English-Speaking-System/01-Templates/自动整理.md`
5. 重启 Obsidian

**开了之后**:每次打开 Obsidian,系统会自动把新表达和新错误归集进两个库、重建复习闪卡。不开也能用,只是这些要你手动做。

> ⚠️ 这个开关是**每台设备单独存的**。以后在另一台电脑上打开同一个仓库,要再点一次。

---

## 第 3 步:配置 ChatGPT 项目(2 分钟)

指令已经按你的参数填好、就在剪贴板里,浏览器也已经打开到项目页。

**详细步骤见 → [配置 ChatGPT 项目](配置ChatGPT项目.md)**

那一页讲清楚了:为什么必须建「项目」而不能贴进普通对话(这是最容易踩的坑)、界面上点哪里、以及两个验证测试。

---

## 装完了,怎么确认一切正常

| 测试 | 应该看到 |
|---|---|
| Obsidian 里按 `Cmd+Shift+E` | 弹出模板选择框,里面有「English Study 剪贴板归档」 |
| 打开 `05-Dashboard/进度仪表盘.md` | 显示表格(而不是一堆代码),内容是「还没有练习记录」 |
| ChatGPT 项目里发「每日输入」 | 一篇你所选领域的英文短文 + 5 个加粗表达 |

三个都对 → 开始你的第一天。日常怎么用见 [日常流程](日常流程.md)。

## 出问题了

| 现象 | 原因 |
|---|---|
| Agent 说它没有网络权限 / 下载失败 | 给它开网络访问;GitHub API 每小时限流 60 次,失败就等会儿再试 |
| Agent 说仓库路径已存在同名文件夹 | 它在保护你已有的数据。确认是不是装过一次,或者换个仓库 |
| 按 `Cmd+Shift+E` 没反应 | 重启 Obsidian;还不行就看设置 → 快捷键里搜 Templater 确认绑定 |
| 仪表盘显示代码不显示表格 | Dataview 的 **Enable JavaScript Queries** 没开 |
| 打开 Obsidian 没有「自动整理」通知 | 第 2 步的总闸没拨;第一天还没有日志时不弹通知也是正常的 |

更多见 [常见问题](常见问题.md)。想知道系统内部怎么运作、或者让 AI 帮你排障,把 [维护知识库](维护知识库.md) 给它。
