# 进阶(可选)

以下功能不影响核心闭环,想要再加。

## 复习闪卡

### 它长什么样

系统会把你练出来的表达自动做成卡片。**正面是中文提示或挖空的句子,背面是目标表达**:

```
不是 think over::overthink
Parents always ____ in their children's lives.::play a crucial role
```

复习时你先看到左边,自己在心里说出英文,再翻面对答案,然后告诉插件「记得 / 不记得」——它按遗忘曲线决定下次什么时候再考你。

### 它和 ChatGPT 里的「表达重测」有什么区别

| | 闪卡(Obsidian) | 表达重测(ChatGPT 热身) |
|---|---|---|
| 你做什么 | 心里想一下,自评记不记得 | **开口说出整句**,它当场判定对错 |
| 能判断你说得对不对吗 | ❌ 不能,只能自评 | ✅ 能,搭配、介词、时态都查 |
| 定位 | 通勤路上随手过一遍的**补充** | **主力**,每天自动进行 |

所以闪卡是可选的——不装也不影响核心训练。

### 怎么用起来

**① 装插件**
Obsidian 设置 → 第三方插件 → 浏览 → 搜 **Spaced Repetition** → 安装并启用。**用默认设置**,尤其别改卡组标签(默认 `#flashcards`,脚本按这个来)。

**② 打开自动重建开关**
就是[手动安装](手动安装.md)第四步那个「Enable startup templates」——**如果你已经开过,这里什么都不用做**。开了之后每次打开 Obsidian,系统会用表达库重建 `07-Review/表达闪卡.md`。

**③ 等几天**
卡片来自表达库,而表达库要靠你每天练习攒。**第一周基本是空的,这是正常的**——文件里会写着「现在还是空的」。攒到 20 条左右开始有复习价值。

**④ 复习**
命令面板(`Cmd+P`)→ 搜 `flashcards` → 选「Spaced Repetition: Review flashcards from all notes」。

> 状态栏右下角出现 `N card(s) due` 就说明卡组被认到了。搜不到命令?搜 `flashcards` 这个词最稳,完整命令名是英文的。

### 两个自动照顾好的细节

- **复习进度不会丢**:重建时会保留插件写的排程标记,你之前背到哪还是哪
- **没有中文释义的表达会被跳过**,并列在文件末尾提醒你——因为卡片正面就是那个中文提示,没有它做不成卡

### 想要发音音频(仅 macOS,可选)

在**你下载解压出来的仓库目录**下跑一次(注意 `scripts/` 不在 Obsidian 仓库里):

```bash
cd <你解压出的 speaking-system 目录>
python3 scripts/build_flashcards.py "<你的 Obsidian 仓库>/English-Speaking-System"
```

它用系统 `say` 给每个表达生成朗读音频并嵌进卡片。**不用反复跑**——之后的自动重建会保留这些音频,攒了一批新表达时再跑一次即可。

非 macOS 用户:装下面的 Text to Speech 插件,选中卡片按快捷键即时朗读。

## 朗读任何选中文字(查发音)
装社区插件 **Text to Speech**,设置里把语音选成 Samantha(或下载 Siri Premium 音色),绑一个快捷键给 "Play/Pause"。

## 自动整理表达库/错误库(不需要 AI!)
系统自带一个「无 AI 版自动整理」模板(`01-Templates/自动整理.md`):每次打开 Obsidian 时,自动把新日志里的表达和错误搬进两个库的「📥 待归类」区(带日期、自动去重)。你只需偶尔花 1 分钟把待归类条目挪到对应分类——顺手就完成了一次复习。
启用(两步,都在 Templater 设置里):
1. **Startup templates** 列表添加 `English-Speaking-System/01-Templates/自动整理.md`
2. 打开 **Enable startup templates** 总开关(⚠️ 这一步在设置界面里,配置文件里改无效——总开关存在设备本地)
**有能跑定时任务的 AI 助手?** 可以升级成每晚智能整理——领域自动归类、相似错误合并、使用记录统计、系统体检、每日简报全都由 AI 完成,你连「待归类」都不用挪。完整任务提示词和三种配置方法见 **[AI 每晚自动整理](AI每晚自动整理.md)**(⚠️ 与本节的启动脚本二选一,不要同时开)。
