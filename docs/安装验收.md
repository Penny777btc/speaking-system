# 装好了吗?三分钟自检

> 装完之后跑一遍,确认整条链路真的通了——**别等到第一次真实练习完才发现归档跑不通**。
> 分两部分:1 分钟的快速检查 + 2 分钟的端到端实测。

---

## 第一部分:快速检查(1 分钟,4 项)

| # | 怎么测 | 应该看到 | 不对的话 |
|---|---|---|---|
| 1 | 看 Obsidian 左侧文件树 | 有 `English-Speaking-System`,展开有 8 个子文件夹(00-Prompts 到 07-Review) | 文件夹没拖对位置,或解压时用了 `unzip` 导致中文文件名失败 |
| 2 | 按 `Cmd+Shift+E`(Win `Ctrl+Shift+E`) | 弹出模板选择框,里面有「**English Study 剪贴板归档**」 | 快捷键没绑,或 Templater 的模板目录填错 |
| 3 | 打开 `05-Dashboard/进度仪表盘.md` | 显示**表格**,写着「还没有练习记录」 | 看到一堆代码 = Dataview 的 **Enable JavaScript Queries** 没开 |
| 4 | ChatGPT 项目里新开对话,发 `每日输入` | 一篇你所选领域的英文短文 + 5 个**加粗**表达 + 开始让你造句 | 指令没贴进**项目**、没保存、或保存后没新开对话 |

四项都过 → 继续做端到端实测。

---

## 第二部分:端到端实测(2 分钟)

前面四项只证明「零件都装上了」,这一步证明**整条数据链路真的通**:复盘 → 解析 → 入库 → 仪表盘。

### ① 复制这份测试复盘

全选复制下面整段(这是一份格式完整的假数据):

```
# 2020-01-01 English Study
## Speaking Time
- Total session: ~60 min
- Your speaking time: ~25 min
- Scored speaking time: ~18 min
- Scored word count: ~1,200
- Scored ratio: ~72%
- Errors per 100 words: ~1.5
## Main Topics
* Installation test
## Strengths
* This is a test entry.
## Key Corrections
### 1. [时态]
❌ I go there yesterday.
✅ I went there yesterday.
### 2. [冠词]
❌ I am teacher.
✅ I am a teacher.
### 3. [搭配]
❌ make a mistake on grammar
✅ make a mistake in grammar
## Error Log
- [介词] ❌ depend to → ✅ depend on
- [用词] ❌ very like → ✅ really like
## New Words & Phrases
- test entry — 测试条目(装好后可删)
## Expressions Used
- 自发用出: test entry
- 任务卡: 0/3
- 本次毕业: 无
## 明日重测清单
- 表达重测(5): test entry
- 任务卡(3): test entry
- 错误重测(2): depend on
## Model Sentence
> This is a test sentence for installation check.
## Tomorrow's Suggestion & Topic
**Speaking Goal**
- 删掉这篇测试笔记
**Tomorrow's Topic**
- 你的第一次真实练习
**引导问题**
1. What do you want to talk about?
2. Why does it matter to you?
3. How would you explain it to a child?
## Overall Evaluation
| 维度 | 评分 | 说明 |
|------|------|------|
| Fluency | 4/5 | 测试数据 |
| Grammar | 3.5/5 | 测试数据 |
| Vocabulary | 4/5 | 测试数据 |
| Communication | 4/5 | 测试数据 |
| **Overall** | 7.8/10 | 测试数据,验收后请删除本笔记 |
```

### ② 在 Obsidian 里归档

按 `Cmd+Shift+E` → 回车(选「English Study 剪贴板归档」)。

### ③ 检查结果

应该在 `02-Daily-Logs/` 里出现一篇 **`2020-01-01 English Study`**。打开它,看笔记属性(Properties)区:

| 属性 | 正确的值 |
|---|---|
| `date` | 2020-01-01 |
| `speaking_time` | 25 |
| `scored_time` | 18 |
| `word_count` | **1200**(不是 1!) |
| `error_rate` | 1.5 |
| `fluency` / `grammar` / `vocabulary` / `communication` | 4 / 3.5 / 4 / 4 |
| `overall_score` | 7.8 |

**十个属性全对 = 归档链路完全正常。**

### ④ 看仪表盘

打开 `05-Dashboard/进度仪表盘.md`,现在应该显示:

- 总览出现「累计:1 次 / 25 分钟」
- 总分趋势里有一行 2020-01-01
- 错误类型趋势里出现「时态、冠词、搭配、介词、用词」

### ⑤ 顺带测「自动整理」(如果你开了那个开关)

关闭 Obsidian 再打开。右上角应弹出一个「自动整理:表达 +1,错误 +5…」的通知,并且:

- `03-Expression-Bank/Expression Bank.md` 里出现「📥 待归类」区,含 `test entry`
- `04-Error-Patterns/Error Patterns.md` 里出现「📥 待归类」区,含那 5 条错误

没弹通知 → Templater 的 **Enable startup templates** 总闸没打开。

### ⑥ 🧹 清理(必做)

**删掉测试产生的所有痕迹**,否则会污染你的统计:

1. 删除 `02-Daily-Logs/2020-01-01 English Study.md`
2. 如果做了第 ⑤ 步:把两个库里「📥 待归类」区的测试条目删掉
3. 如果装了闪卡插件:打开 `07-Review/表达闪卡.md`,里面可能有一张 `test entry` 的卡,下次自动重建时会消失(或手动删掉表达库条目后立即重建)

## 验收结果对照

| 情况 | 说明 |
|---|---|
| 快速检查 4 项 + 端到端全过 | ✅ **完全装好了**,可以开始第一天 → [日常流程](日常流程.md) |
| 快速检查过,但归档后属性是空的 | 复制时格式被拍平了(手机端常见)。桌面端复制一般正常;实在不行手动填属性也能用 |
| `word_count` 显示 1 而不是 1200 | 你的模板是旧版本。重新下载覆盖 `01-Templates/English Study 剪贴板归档.md` |
| 仪表盘有数据但不显示图表 | Dataview 的 JS 查询没开 |
| 第 ⑤ 步没反应 | 自动整理开关没开——这是可选功能,不影响核心使用 |

其他问题 → [常见问题](常见问题.md)

---

## 什么时候该重新跑一次验收

- **换了电脑 / 新设备打开同一个仓库**(Templater 的总闸是每台设备单独存的)
- **更新了系统文件**之后
- **归档突然不工作了**——先跑一遍这个,比瞎猜快
