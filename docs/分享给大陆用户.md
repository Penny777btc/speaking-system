# 分享给访问不了 GitHub 的用户

> 给项目维护者看的。大陆用户直连 GitHub 常有困难,这里是几种分发方式和各自的坑。

---

## ⚠️ 先知道最关键的一件事

**自动安装(AI Agent)依赖 GitHub 下载 Obsidian 插件**:

```
https://api.github.com/repos/SilentVoid13/Templater/releases/latest
https://github.com/.../releases/download/...
```

连不上 GitHub 的话,agent 会把文件都装好、却卡在插件那一步,系统跑不起来。

**而手动安装不受影响**——它走 Obsidian 客户端自带的插件市场,通常能正常下载。

> ✅ **给大陆朋友一律推荐[手动安装](手动安装.md)**,不要推自动安装。

---

## 方案一:离线完整包(最省事,推荐先用这个)

打一个**什么都有**的压缩包——系统文件、两个插件、全部文档、单独的指令文本。用户下载解压后**不需要访问任何外部网站**(除了 ChatGPT 本身),照着入口文档做就行。

```bash
bash scripts/make_offline_bundle.sh
```

产物在桌面:`口语系统-完整包.zip`(约 700KB,可以直接发微信)。

解压后长这样,**文件夹名本身就是操作说明**:

```
口语系统-完整包/
├── 👉从这里开始.md            ← 用户第一眼看到这个
├── ChatGPT指令-改完直接复制.txt  ← 纯文本,开头写了改哪三处
├── 1-把这个文件夹拖进Obsidian/
├── 2-插件-装不上时用/          ← 插件市场连不上时的救急文件
└── 说明文档/                   ← 7 份文档,离线可读
```

**为什么这个方案最适合大陆用户**:插件已经预下载好了,连不上 GitHub 也不影响;文档全在本地,不用点任何链接。

**代价**:是快照,你以后更新了他们不知道。所以发的时候说一句「以后想要新版找我要」,或者配合方案二。

> 插件文件的分发是合规的:Templater 和 Dataview 都是 MIT 许可,包里附了来源和版权说明。记得偶尔重新打包一次以更新插件版本。

---

## 方案二:Gitee 镜像(能持续更新)

### 为什么不能简单复制

即使文件镜像过去,文档里写死的 `raw.githubusercontent.com` 链接(agent 抓安装手册、抓夜间任务提示词用)在大陆照样打不开。**必须一并替换**,仓库里有现成脚本。

### 步骤

**1. 在 Gitee 建仓库**
- 注册 [gitee.com](https://gitee.com)(需实名认证)
- 新建仓库 → 可以用「从 GitHub/GitLab 导入仓库」直接导入,也可以建空仓库后推送
- 仓库名建议保持 `speaking-system`

**2. 生成国内版**

在你的 GitHub 仓库目录下运行:

```bash
bash scripts/make_cn_mirror.sh <你的Gitee用户名> speaking-system
```

它会在 `../speaking-system-cn/` 生成一份副本:
- 所有 `raw.githubusercontent.com` / `github.com` 链接 → 换成 Gitee 对应地址
- README 顶部自动加一段「国内镜像版 + 请走手动安装」的提示

**3. 推上去**

```bash
cd ../speaking-system-cn
git init && git add -A && git commit -m "CN mirror"
git remote add origin https://gitee.com/<你的用户名>/speaking-system.git
git push -u origin main --force
```

**4. 以后更新**

GitHub 那边改完之后,重跑一次脚本再 push 即可(脚本每次都是全新生成,不会积累旧内容)。

### 注意

- Gitee 的**开源仓库需要人工审核**才能公开访问,提交后等一两天
- Gitee 对仓库大小和流量有限制,本项目很小,不会触及

## 方案三:文档搬到国内平台(补充,不推荐单独用)

把 `docs/` 的内容搬到语雀 / 飞书文档,方便对方随时查阅。

**但模板文件还是得另外发**——所以这只能作为方案一/二的补充,不能单独用。而且维护两份文档必然漂移,除非你只搬「日常流程」这种不常变的页。

---

## 如果对方连 Obsidian 插件都装不上

少数情况下,Obsidian 的插件市场也连不上。三个办法:

1. **让能上 GitHub 的人代下**:从 [Templater](https://github.com/SilentVoid13/Templater/releases) 和 [Dataview](https://github.com/blacksmithgu/obsidian-dataview/releases) 的 Releases 各下载 `main.js`、`manifest.json`、`styles.css`,发给对方
2. 对方把文件放进 `<仓库>/.obsidian/plugins/templater-obsidian/` 和 `.../dataview/`,重启 Obsidian,在「第三方插件」列表里启用
3. 之后照[手动安装](手动安装.md)的第 2 步「配」那部分继续

> 你也可以把这两个插件的文件一起打进你发的压缩包里,对方解压即用——最省事,但记得偶尔更新版本。

---

## 一句话总结

| 你想要 | 用哪个 |
|---|---|
| **发给朋友、发群里、传网盘** | 离线完整包(方案一)——插件都在里面,最省心 |
| **长期维护、能推送更新** | Gitee 镜像(方案二) |
| **两者都要** | 平时发离线包,同时挂个 Gitee 供人自取新版 |

无论哪种,**都告诉对方走手动安装**(自动安装要从 GitHub 下插件)。

另外提醒对方:解压时**双击解压**,别用命令行 `unzip`(中文文件名会失败)。
