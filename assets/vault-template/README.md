# 🎙️ 口语成长系统(GPT Live + Obsidian)

> 光练不记,等于白练。这套系统把每次开口变成可追踪的成长记录。

---

## 使用前 vs 使用后

| | ❌ 使用前 | ✅ 使用后 |
|---|---|---|
| 练完之后 | 对话再爽,下课就忘 | 每次 15 分钟,自动沉淀一篇结构化记录 |
| 纠错 | 今天纠正的错误,明天照犯 | 中式英语陷阱进「错误模式库」,定期回看不再重复犯 |
| 好句子 | 说过的好句子,转头就没了 | 金句进「表达库」,慢慢攒成自己的语料 |
| 进步 | 练了一个月,进步多大完全说不清 | 仪表盘上评分曲线一目了然,强项弱项清清楚楚 |
| 明天练什么 | 每次开口先冷场三分钟 | 昨天的复盘已经写好明日话题 + 引导问题 |

## 首次安装(只做一次,约 5 分钟)

1. **把整个 `English-Speaking-System` 文件夹放进你的 Obsidian 仓库**(或直接把它作为一个新仓库打开:Obsidian → Open folder as vault)。
2. **安装两个社区插件**:设置 → 第三方插件 → 关闭安全模式 → 浏览:
   - **Templater**(一键生成当天笔记)
   - **Dataview**(仪表盘需要;设置里开启 "Enable JavaScript queries")
3. **配置 Templater**:设置 → Templater →
   - Template folder location: `English-Speaking-System/01-Templates`
   - 建议再设一个快捷键:设置 → 快捷键 → 搜 "Templater: Create new note from template"
4. **在 ChatGPT 建一个项目**(如「英语口语 B1→C1」),把 `00-Prompts/4-项目指令(完整版).md` 里的指令贴进项目 Instructions——四个触发词(每日输入/开始口语练习/按模板复盘/月度模考)全部由它驱动。

## 每天怎么用(输入+口语+复盘,全部在 ChatGPT 项目「英语口语 B1→C1」内进行)

> 完整节奏和季度目标见 [B1到C1路线图](06-Roadmap/B1到C1路线图.md)。练习一律在 ChatGPT 的**项目**里发起(项目能记住历史对话,错误重测靠它);普通对话里旧的触发词依然可用,作为快速模式。

### 核心原则:一天 = 一个 Live 会话 = 一次复盘 = 一次归档

**默认流程:全 Live 日(输入、口语、复盘全在一个语音会话里)**
1. 进入项目,打开 **Live 语音**,说 **「每日输入」**——它会口头预告主题 → **完整朗读整篇文章**(这就是你的听力环节)→ 逐个报出 5 个表达 + 中文解释 → 然后逐题口头讨论(细节理解 → 观点 → 用新表达复述)
2. 接着说 **「开始口语练习」**——旧错误重测热身 → 自由对话 8–10 分钟
3. 退出语音回到文字界面——**文章全文和全部对话都在会话记录里**,想精读就滚动回看 → 打字发 **「按模板复盘」** → 复制 → `Cmd+Shift+E` 归档

**可选加餐:精读日(每周 1–2 天,文字会话 + 听写答题)**
「每日输入」(文字版,带加粗排版)→ 听写麦克风答 3 题 → 听写继续「开始口语练习」→ 复盘归档。
听写转写不洗错误、能逐题对答案——**用来把 Live 抓不干净的顽固错误彻底清掉**。

自由对话卡壳时:聊昨天复盘的明日话题,或从 [话题库](00-Prompts/3-话题库(按季度爬坡).md) 挑一个。
每月 1 号改说 **「月度模考」**,做一次雅思式测评。

**第 4 步:归档(10 秒)**
在 ChatGPT 里点复盘消息的**复制**按钮 → 切到 Obsidian 按 **Cmd+Shift+E** → 回车选「English Study 剪贴板归档」。
笔记自动创建:标题日期自动命名、归档进 `02-Daily-Logs/`、**四维评分/总分/练习时长自动解析进 frontmatter**(仪表盘直接可用)、正文自动粘好。
(如果剪贴板里没有复盘内容,会生成一篇带提示的空模板,不会报错。)

**小提示:**如果 Live 会话生成在项目外面,练完把它拖进项目里,日后错误重测才能引用到它。

**每周日加 5 分钟:**
- 打开 `05-Dashboard/进度仪表盘.md` 看评分趋势
- 把本周金句挪进 `03-Expression-Bank/`,高频错误挪进 `04-Error-Patterns/`
- 朗读一遍错误模式库——这是防止「明天照犯」的关键动作

## 设计原则(为什么这么做)

- **模板即指令**:同一份 Markdown,既是 Obsidian 笔记模板,也是发给 GPT 的复盘指令。格式每天统一,数据才能沉淀、才能画曲线。
- **GPT 负责填内容,模板负责保结构**:Templater 保证日期和 frontmatter 永远正确,GPT 输出不完整时模板兜底。
- **每次只记 3 个错误**:避免信息过载。建立信心比纠错更重要,只盯着错误很容易练着练着就放弃。
- **纯 Markdown**:数据永远属于你,不绑定任何平台。
